05 / 接下来按此顺序实施

  1. 内容归档与清洗：逐条抓取 263 条目录产品及 58 条推荐页面，保存详情、图片、参数、媒体路径；核对重复型号、错误单位、失效链接，并建立旧 URL → 新 URL 映射。
  2. 资料核实：确认公司法定中英文名、在售目录、联系方式、人数与销售额、证书归属和服务政策。缺失资料保持待补状态。
  3. 设计样板：先完成首页、分类页、产品详情页的桌面与手机样板，再按同一体系扩展公司、工厂、质量、资源和联系页面。
  4. 实现与内容导入：建立产品、分类、新闻、视频、证书及公司信息的数据结构；若需要日常编辑，选择轻量内容后台，不提前强绑技术框架或安装大型 CMS。
  5. 询价与 SEO：配置真实询价接收渠道、关联产品、校验与失败重试；保留有效旧链接或配置重定向，生成 sitemap、页面标题与结构化信息。
  6. 验收与发布：逐页核对内容、产品总量和图片；测试手机菜单、搜索、筛选、媒体、参数表和表单真实收件，检查构建与链接后再切换正式站点。

阶段成果：内容资产库 → 三个核心页面样板 → 全站可浏览预览 → 后台与询价接通 → 全量核验 → 正式发布。本次交付为第一轮内容盘点与排版规划。
