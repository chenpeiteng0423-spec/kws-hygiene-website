The details.

KWS Electric Fragrance Aroma Diffuser Scent Air Machine CE Certificate

Features


1. Built with the intelligent timing system, support work periods and intensity setting by yourself.
2. Support stand alone, wall mount and HVAC connection.
3. Built with fan and with a lock for timer and bottle.
4. 500ml bottle capacity and 2000-3000m3 coverage.
5. One-time use plastic atomizer and bottle.

Technology

Principle: the machine is to use Venturi nanotechnology diffusing fragrance oil into particles, which spread out as visible mist.
HVAC connection: the machine is connected via an hose attached to a small PU tube which is installed in the A/C duct or you can put the machine on the ceiling near the air outlet or inlet.
